# Brad Coates - Telecom Consultant

A super simple, mobile-first personal website. Just a photo, bio, and call-to-action. No frills, no complexity.

## 🎯 What It Is

- **One page** with your photo and bio
- **Mobile-first** design that works perfectly on phones
- **Clean and simple** - no navigation, no fancy animations
- **Fast loading** - just HTML and CSS
- **Easy to customize** - update your photo and bio

## 📱 Mobile Simple

The site is designed to be viewed primarily on mobile devices. It's clean, readable, and gets straight to the point.

## 🛠️ Technologies

- **HTML5**: Simple, semantic markup
- **CSS3**: Clean, mobile-first styling
- **Google Fonts**: Inter font for readability

## 🚀 Getting Started

1. **View locally**: Open `index.html` in your browser
2. **Add your photo**: Replace the placeholder with your actual photo
3. **Customize**: Update the bio text and contact info
4. **Deploy**: Upload to Netlify, GitHub Pages, or any web host

## 📸 Adding Your Photo

Replace the photo placeholder in `index.html`:

```html
<!-- Replace this: -->
<div class="photo-placeholder">
    <span>📸</span>
</div>

<!-- With this: -->
<img src="your-photo.jpg" alt="Brad Coates">
```

## 🌐 Deployment

### Netlify (Recommended)
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop your project folder
3. Done! Your site is live

### GitHub Pages
1. Push to GitHub
2. Enable GitHub Pages in repository settings
3. Select source branch (usually `main`)
